# 初期実装の範囲

日付: 2026-10-12

開発環境はXcode 26.3 (17C529)、Apple Swift 6.2.4。
Swift PackageでDomainとApplicationを分離し、AppleのUI・保存フレームワークに依存しない基礎から実装する。
PackageのiOS 17指定は開発上の暫定値であり、配布対象OSの確定を意味しない。

金額はInt64の正数、入力はASCII数字列、加算と減算はオーバーフロー検出を行う。
月集計は開始を含み終了を含まないRange<Date>を受け取る。
日本時間での月境界生成は、仕様書にある事前承認の回答を待つ。
作成・更新のUse CaseはRepository経由で保存し、更新時にID・作成日時を保持する。
重複カテゴリIDは任意の1件を選ばずエラーにする。

カテゴリ区分の不変性とアーカイブ保持のモデルは仕様案をレビューするためのコードであり、永続化は未実装。
メモ・カテゴリ名の上限、初期カテゴリ、予算の未設定表現、同期重複の統合、バックアップ形式と復元方式は未確定。
バックアップRepositoryは一括適用の契約のみで、ファイル形式や復元アルゴリズムを確定していない。

この段階では利用者データの保存、CloudKit接続、署名・配布を行わない。
次段階は仕様提案の承認、Applicationの追加テスト、Xcodeアプリと永続化の実装。
