# 実機の受け入れ確認

確認は未実施。iPhoneとiPad、同じApple Account、開発用CloudKit Container、架空のデータを使用する。実際の家計データがある場合は最初にJSONバックアップを保存する。

1. Xcodeで実際のTeam・Bundle ID・Containerを設定し、iCloud／CloudKitとRemote notificationsを確認する。2台に同じ構成をインストールする。
2. 支出入力から数字パッドで保存し、履歴・集計・予算に反映されることを確認する。不正金額・長すぎるメモでは入力を維持することを確認する。
3. 履歴で編集、削除のキャンセル、削除の確定を操作する。カテゴリ名変更の履歴反映、アーカイブ後の参照保持、解除、並べ替えを確認する。
4. アプリを終了・再起動し、カテゴリ・取引・予算が残ることを確認する。
5. 片方で作成・編集・削除し、もう片方の画面に反映することを双方の方向で確認する。active復帰時と表示中の両方で確認する。
6. オフラインで入力し、再接続後に他端末へ反映することを確認する。iCloud未ログイン、一時障害、容量不足について端末保存と起動の結果を記録する。
7. 同じ取引の同時編集、片方で削除・片方で編集、初回カテゴリ作成の競合、同じ月の予算設定の競合を起こして結果を記録する。重複レコードを自動削除していないことを確認する。
8. CSVとJSONをOSのファイルUIで出力する。日本語・改行・引用符・式開始文字を含む架空のメモを確認する。空のテストストアにJSONを復元して値を照合する。
9. 再追加で件数が増えないこと、上書きで既存の別IDデータが残ること、不正ファイルと競合を拒否すること、プレビューのキャンセルが書き込まないことを確認する。
10. VoiceOver、最大Dynamic Type、横向き、iPad分割表示で主要操作・チャートと同じテキスト情報を確認する。10,000取引で復元中の応答性・メモリ・操作時間を測定する。
11. テスト用ストアで初期化失敗を起こし、データを削除・別ストアに切り替えず再試行が表示されることを確認する。

記録項目: 日時、アプリ構成、OS、端末、AC番号、操作、期待値、実測結果、残課題。CloudKit本番スキーマへの反映やリリースは、この記録とモデルのレビュー後に行う。

## 追加機能と保存時終了の確認

1. 既存アプリを削除せず更新し、既存の取引・ジャンル・月間予算を確認する。データを消さずに移行できることを確認する。
2. Xcodeから実機で実行し、支出・収入をそれぞれ保存、連続保存、メモを含む保存、編集、再起動後の保存を行う。終了した場合は例外で停止したスタックと、Devices and Simulatorsのクラッシュ記録を採取する。Consoleの `PersonalKakeibo` / `Entry` / `Persistence` の最後の記録を確認する。原因特定前に終了が解消したと扱わない。
3. 入力・編集・繰り返し記録のメモを入力し、下方向のスワイプでキーボードが隠れることと、入力が保持されることを確認する。
4. 3列のジャンルをタップ・長押しし、通常タップで選択、長押しで星と設定完了表示が出ることを確認する。再起動、収支切替、アーカイブを確認する。VoiceOverでは「初期ジャンルに設定」アクションを使う。
5. カレンダーを開き、記録のある日のドット、日付選択、月移動、保存・日付編集・削除後の反映を確認する。
6. 食費の日額・月額予算を設定し、収支の保存・編集・削除の残額を照合する。過去日、日付・月境界、超過、空欄での解除を確認する。
7. 毎日・毎週・毎月の予定を登録し、未処理予定を修正して記録、スキップ、無効化、再起動を確認する。31日開始の予定で2月末と翌月31日を確認し、同じ回を重複登録できないことを確認する。記録済み取引を削除しても予定が未処理に戻らないことを確認する。
8. 通知を初めて有効化した際の許可・拒否を別のテスト端末で確認する。通知枠を近い未来へ変更し、アプリ表示中・バックグラウンド・終了中に配信を確認する。通知のタップで起動した場合もリマインダー画面を開くことを確認する。通知対象なし、予定無効化、全枠停止、重複時刻拒否も確認する。
9. 追加データのJSONを復元し、同じ回が再度未処理にならないことを確認する。CloudKit構成では2台で予算・予定・処理状態の反映と、同じ回をオフラインで同時記帳した場合の重複警告を確認する。

## 金額消去・項目別予算通知

- 「1」→「00」で100円になること、18桁入力後の「00」が追加されないことを確認する。
- 金額表示とテンキーを下へスワイプして金額だけが消え、メモ・日付・ジャンルが維持されることを確認する。上・横スワイプ、入力部分外のスクロールでは消去されないことも確認する。
- VoiceOverの「金額を全消去」アクションと「ゼロを2桁入力」の読み上げを確認する。
- 食費の月額31,000円と別項目の日額500円を通知対象にし、各時刻に項目別の通知が届くことを確認する。10月は食費が約1,000円、日額設定の項目は500円となる。
- 予算変更・解除、通知オフ、アーカイブ、時刻変更後に古い予約が残らないことを確認する。既存のまとめ通知からの更新時に通知が二重にならないことも確認する。
- 前景・背景・終了状態から通知を開き、リマインダー画面に移動することを確認する。月をまたいだ復帰で概算が更新されることを確認する。
